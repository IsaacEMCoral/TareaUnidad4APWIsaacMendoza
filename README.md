# MercApp

## Autor
- **Nombre del estudiante:** Isaac Mendoza
- **Proyecto:** MercApp

## Funcionalidades implementadas
- **CRUD de productos**:
  - Crear, listar, editar y eliminar productos.
  - Campos: productId, name, description, category, price, stock.
- **Frontend SPA (Vue 3 + Vite)**:
  - Rutas internas con Vue Router (`/products`, `/edit/:id`).
  - Formularios con validación y mensajes de éxito/error.
- **Backend API (Express + MongoDB Atlas)**:
  - Backend en **Railway**.
  - Conexión segura con MongoDB Atlas.
- **Frontend**:
  - En **Netlify**.
- Documentación en **GitHub Pages**.
